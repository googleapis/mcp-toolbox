# Link Forms, Path Mapping, and Traps

Reference guide for path-to-URL mappings and common documentation link traps in `mcp-toolbox`.

## Path to URL Mapping

`.hugo/hugo.toml` mounts `../docs/en` as `content` at site root (`defaultContentLanguageInSubdir = false`).
- **No `/en/` or `/docs/` prefix exists in rendered URLs.**
- URLs use pretty paths (e.g. `docs/en/integrations/postgres/source.md` → `/integrations/postgres/source/`).

## Canonical Link Form

Always use **file-relative paths with the `.md` extension** (e.g. `[Postgres](../postgres/source.md)`).
- **Directory-style (`../postgres/`)**: Works in Hugo, fails in Lychee.
- **Site-absolute (`/integrations/postgres/source/`)**: Passes Lychee, but breaks versioned builds.

### Why Site-Absolute Links Leak
Hugo does not prefix hand-written absolute paths with `baseURL`.
- Push to `main` deploys to `https://mcp-toolbox.dev/dev/`
- Releases deploy to `https://mcp-toolbox.dev/<version>/`
- PR previews deploy to `/`

A site-absolute path like `](/reference/cli/)` always resolves to the root domain (`mcp-toolbox.dev/reference/cli/`), jumping users out of `/dev/` or archived release documentation into the latest release.

## Shortcode-Generated Links

Some links only exist in rendered HTML generated by Hugo shortcodes:
- `{{< compatible-sources >}}`: Renders sources supporting a tool.
- `{{< list-tools >}}`: Renders tools under a source.
- `{{< samples-gallery >}}`, `{{< list-prebuilt-configs >}}`, `{{< list-db >}}`: Directory listings.
- `{{< include >}}`, `{{< regionInclude >}}`: Inlines external content.
- `shared_tools` frontmatter: Injects inherited tool links for managed databases.

To check shortcode-generated links, build the site and crawl `public/` using Lychee.

## Common Traps

- **`ignoreFiles` in `hugo.toml`**: Files listed under `ignoreFiles` exist on disk (passing Lychee) but are not rendered by Hugo (404 live).
- **Missing `type: docs`**: An `_index.md` missing `type: docs` defaults to the standard Docsy layout without rendering child page links.
- **Leaf-to-Section Promotion**: When `foo.md` is converted into a directory `foo/_index.md`, old links to `foo.md` break.
- **Two `getting-started` directories**: `docs/en/getting-started/` and `docs/en/documentation/getting-started/` both exist; resolve relative paths against the actual target file.
- **Missing Aliases**: When renaming or moving docs pages, add an `aliases:` frontmatter entry to prevent dead links from external bookmarks.
